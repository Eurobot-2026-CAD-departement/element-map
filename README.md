# Element map

CAD of the **elements of the game map** and the supports used to equip it.

## Contents
- `granary/` — granary CAD files + assembly (this part of the map changes every year)
- `hazel nut crate/` — hazelnut crate parts
- `assembly/`, `assembly decoupage/` — assemblies and laser-cutting ("découpage") files, including the granary upper stages
- `crate with weights + balise/`, `support balise/`, `double support/` — crate/beacon supports
- `pi camera support*`, `pi camera adjustable holder`, `raspberry-pi-camera-support`, `raspberry-pi-camera-lens` — Raspberry Pi camera mounts
- `decoupage map + cover ensi`, `ensi cover.SLDPRT` — map cover for the ENSI competition
